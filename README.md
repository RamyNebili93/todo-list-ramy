# 📝 Todo List de Ramy Nebili

## 🎯 Description
Ce projet est une **Todo List interactive** développée en **HTML**, **CSS** et **JavaScript**.  
Elle permet d’ajouter, cocher et supprimer des tâches, tout en sauvegardant automatiquement la liste grâce au **LocalStorage** du navigateur.

## ⚙️ Fonctionnalités
- ➕ Ajouter une tâche avec le bouton ou la touche **Entrée**  
- ✅ Cocher une tâche terminée  
- ❌ Supprimer une tâche  
- 💾 Sauvegarde automatique (même après rechargement de la page)  
- 🔢 Compteur dynamique de tâches terminées (v1.2)
